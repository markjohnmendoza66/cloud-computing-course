## Introduction

This laboratory activity explores three major public cloud platforms: Amazon Web Services, Microsoft Azure, and Google Cloud Platform.

The purpose of the activity is to compare their infrastructure and services, determine their strengths, and select suitable cloud solutions for different business situations.

---

## Cloud Platforms Investigated

### Amazon Web Services

AWS provides cloud services for computing, storage, databases, networking, security, analytics, and many other workloads.

### Microsoft Azure

Azure provides cloud and hybrid solutions with strong integration with Microsoft technologies.

### Google Cloud Platform

Google Cloud provides services for computing, storage, data analytics, artificial intelligence, machine learning, and Kubernetes.

# Cloud Hosting Options

If the investigated Linux server were moved to a cloud environment, it could be hosted using the following services:

| Provider     | Cloud Service          |
| ------------ | ---------------------- |
| AWS          | Amazon EC2             |
| Azure        | Azure Virtual Machines |
| Google Cloud | Compute Engine         |

## AWS

Amazon EC2 can provide a Linux virtual machine with configurable computing, storage, and networking resources.

## Azure

Azure Virtual Machines can host Linux-based workloads while providing configurable virtual machine sizes and storage options.

## Google Cloud

Compute Engine can provide a Linux virtual machine whose machine type and storage can be selected according to workload requirements.

---

# Key Takeaway

This mission demonstrated that AWS, Azure, and Google Cloud provide many similar fundamental services. However, each provider has areas where it can be especially appropriate, so cloud selection should be based on the requirements of the organization.
