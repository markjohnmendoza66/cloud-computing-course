## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform operated by Amazon. It provides organizations with on-demand services for computing, storage, databases, networking, security, analytics, and other technologies. Instead of maintaining all computing equipment on-site, businesses can use AWS resources through the internet.

## 2. Global Infrastructure

AWS organizes its infrastructure into Regions and Availability Zones. Regions represent separate geographic locations, while Availability Zones are isolated locations within a Region. This design helps organizations build applications that can remain available and can serve users from different geographic areas.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface for managing AWS resources. It allows users to create services, configure resources, monitor workloads, manage security permissions, and view their cloud environment.

## 4. Four Core Services

### Amazon EC2

Amazon EC2 provides virtual computing capacity that can be used to run applications and operating systems.

### Amazon S3

Amazon S3 is an object storage service used for storing files, media, backups, datasets, and other information.

### Amazon VPC

Amazon VPC creates a logically isolated network environment where AWS resources can communicate securely.

### AWS IAM

AWS IAM controls access to AWS resources by managing identities, roles, permissions, and policies.

## 5. Three Advantages

1. AWS provides a large variety of services that can support different types of applications.
2. Its global infrastructure allows organizations to deploy workloads in different geographic locations.
3. AWS resources can be scaled according to changes in application demand.

## 6. Typical Enterprise Use Cases

AWS can be used for:

* Website hosting
* Mobile application backends
* Business databases
* Backup and recovery
* E-commerce platforms
* Data analytics
* Enterprise applications
* Artificial intelligence workloads
* Software development and testing
