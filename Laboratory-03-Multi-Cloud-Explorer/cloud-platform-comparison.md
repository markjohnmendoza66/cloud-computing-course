## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS has a very extensive collection of cloud services covering infrastructure, databases, storage, networking, security, analytics, and application development. Because of this variety, AWS can support many different workloads without requiring an organization to use multiple cloud providers.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the most suitable provider for Microsoft-based environments. Its integration with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft technologies can simplify cloud adoption for existing Microsoft customers.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud has a strong position in AI, machine learning, data analytics, and Kubernetes. Google Kubernetes Engine provides a managed Kubernetes platform, while Google Cloud also offers services for developing and deploying machine learning applications.

### 4. Which cloud platform would you personally choose and why?

I would choose Microsoft Azure because I think its integration with enterprise technologies makes it a useful platform for organizations that already have established IT environments. It also provides a wide selection of services for computing, networking, databases, security, and application development.

## Summary

The three platforms provide equivalent solutions for many fundamental cloud requirements. The differences become more noticeable when considering areas such as enterprise integration, AI capabilities, global infrastructure, pricing models, and specialized services.
