# Cloud Computing Reflection Paper

Cloud computing has become an important part of my daily life because I use many cloud-based applications for communication, entertainment, file storage, and productivity.

Three cloud services that I regularly use are Google Drive, Messenger, and Canva. Google Drive is an example of Software as a Service (SaaS) because it allows users to store and manage files online. It uses a public cloud deployment model because millions of users share the same infrastructure.

Messenger is also an example of SaaS because it provides communication services through the internet. Like Google Drive, it mainly uses a public cloud deployment model.

Canva is another example of SaaS because it allows users to create and edit designs online. It also relies on a public cloud infrastructure.

Version control is essential in cloud computing because it allows developers to monitor changes, correct errors, and restore previous versions of files when necessary. GitHub provides a platform where teams can collaborate efficiently while maintaining an organized history of changes.

As a student, learning Git and GitHub will help me develop valuable skills that I can use in future projects and professional work environments.
